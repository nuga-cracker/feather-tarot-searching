# 🕊️ Divine Feather Messenger Library

실물 오라클 카드인 **'Divine Feather Messenger' (By Alison DeNicola)**를 사용할 때, 가이드북을 뒤적이는 번거로움을 해결하기 위해 만든 디지털 도감 및 검색 툴입니다.

## ✨ 주요 기능

- **초스피드 검색**: 카드 이름의 일부만 입력해도 연관 검색어가 즉시 나타납니다.
- **A-Z 인덱스**: 상단의 알파벳 버튼을 눌러 특정 철자로 시작하는 카드를 바로 필터링할 수 있습니다.
- **상세 메시지 제공**: 카드의 영문 메시지 핵심 요약과 한국어 해석, 에너지, 원소, 확언(Affirmation) 등을 한눈에 확인합니다.
- **모바일 최적화**: 실물 카드로 리딩을 하면서 스마트폰으로 간편하게 조작할 수 있도록 설계되었습니다.

## 🚀 시작하기 (GitHub Pages 활용)

1. 이 저장소의 `index.html` 파일을 다운로드하거나 복사합니다.
2. 본인의 GitHub Repository에 업로드합니다.
3. **Settings > Pages**에서 브랜치를 `main`으로 설정하고 배포합니다.
4. 생성된 URL에 접속하여 바로 사용하세요!

## 📖 카드 구성 및 정보 (Deck Info)

본 라이브러리는 다음의 44장 전체 카드 데이터를 포함하고 있습니다:

| 분류 | 내용 |
| :--- | :--- |
| **신성한 치유자 (White)** | White Swan, White Turkey, White Eagle, White Owl |
| **일반 메신저** | Blackbird, Bluebird, Eagle, Hawk, Owl, Raven 등 40종 |
| **속성 정보** | 에너지, 계절, 원소(지/수/화/풍), 색상 |
